Quick Linking Guide

  • Instagram: Switch to a Business/Creator account, link a Facebook Page, and generate a token with instagram_content_publish.
  • YouTube: Enable YouTube Data API v3 in Google Cloud Console and use an OAuth token with youtube.upload scope.
  • Media Rules: Use public HTTPS URLs so Cloudflare's Cron worker can fetch and publish on schedule.

How to Get Your Account ID & Access Token

1. Instagram (Business / Creator)

  1. In the Instagram app, switch to a Professional (Business) account and link it to a Facebook Page.
  2. Go to developers.facebook.com → create a Business App → open Graph API Explorer.
  3. Select permissions instagram_basic, instagram_content_publish, and pages_show_list, then click Generate Access Token.
  4. Query me/accounts?fields=instagram_business_account to copy your 17-digit IG User ID.

2. YouTube (Videos & Shorts)

  1. Open console.cloud.google.com, create a project, and enable YouTube Data API v3.
  2. Go to OAuth 2.0 Playground (developers.google.com/oauthplayground), select YouTube Data API v3 → .../auth/youtube.upload, and authorize your Google account.
  3. Exchange the authorization code for an Access Token.
  4. Copy your YouTube Channel ID (starts with UC...) from YouTube Studio → Settings → Advanced Settings.

3. LinkedIn, X & Facebook

Create an app in the respective developer portal (LinkedIn Developers with w_member_social, or X Developer Portal with OAuth 2.0 tweet.write), copy your profile URN/ID and Bearer token, and paste them into Link Account.
